# Polices de départ pour Sequens

Décompressez le ZIP et placez le dossier `Fonts` à la racine du stockage web, à côté de `Frames` et `Stickers`. Conservez la majuscule de `Fonts`.

Si `Fonts/catalogue.json` existe déjà, fusionnez ses entrées `fonts` avec celles du pack en gardant un seul objet par `id`. Copiez aussi les fichiers et leurs licences.

Dans Frame Builder, ouvrez **Ressources → Texte → Vérifier les polices en ligne**. Sélectionnez ensuite une police pour le titre. Sequens utilise le même catalogue pour charger la police référencée dans le modèle.

Les fichiers fournis sont les variantes latines WOFF2, normal 400, distribuées par Fontsource. Les licences SIL Open Font License 1.1 et mentions de copyright sont dans `licenses/`.
